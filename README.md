# BIO511_Project: Resistance genes in Klebsiella pneumoniae CCUG 58547

Course project, BIO511 Bioinformatics in Genomics, University of Gothenburg (autumn 2026).
Authors: Sacha Ricort & Pedro Daniel

## Question
Does the genome of *K. pneumoniae* CCUG 58547 carry the carbapenemase gene VIM-1,
and which additional antibiotic resistance genes can be detected?

## Background

VIM-1 is a metallo-beta-lactamase that confers resistance to carbapenems.
Confirming it, and screening for other resistance genes, from a sequenced genome
is a standard use of whole-genome sequencing in resistance surveillance.

## Data
- Species: *Klebsiella pneumoniae*, strain CCUG 58547 (CCUG culture collection)
- Expected genome size: ~5.2 Mbp; expected coverage: ~24x
- Raw data: not yet available.
